# 小红书热点选题创作流水线（人工审核版）

## 完整工作流

### Phase 1: 热点选题生成 (调用 hot-topics-inspiration)
**输入**: 账号人设信息
**输出**: 
- 10个精选热点（每个账号独立抓取）
- 每个热点包含：选题标题（≤20字）、四层大纲结构
- 关联性验证（Tier 1/Tier 2）

**调用方式**:
```
skill(name="hot-topics-inspiration")
```

### Phase 2: 选题筛选与确认
用户从10个选题中选择1-3个进行深度创作

### Phase 3: 深度文案创作 (调用 xhs-research-copywriting)
**输入**: 
- 选定选题的四层大纲
- 参考素材链接/文件（可选）

**输出**:
- 1500字深度长文（纯文本，无Markdown）
- 符合人设的真实叙事风格
- 10+个相关话题标签

**调用方式**:
```
skill(name="xhs-research-copywriting")
```

### Phase 3: 输出审核与发布准备（人工确认）
**输出文件**:
- 选题清单（Markdown表格，含10个选题）
- 深度文案（纯文本，可直接复制到小红书）
- 话题标签列表（10+个）

**人工审核环节**:
1. 查看桌面输出的文案文件
2. 人工审核文案质量与人设一致性
3. 确认无误后，手动复制到小红书发布
4. 或继续调用 xhs-auto-publisher 进行自动发布（可选）
5. 一键排版 → 选择"简约基础"模板
---


**调用方式**:
```
skill(name="xhs-auto-publisher")  # 可选，需人工确认后执行
```

## 故障处理

### 场景1：选题关联性不足
→ 重新抓取热点，扩大筛选范围

### 场景2：文案创作偏离人设
→ 回退到Phase 2，重新注入人设参数

### 场景3：文案需修改
→ 根据人工审核意见，调用创作Skill修改特定段落

## 使用示例

**用户指令**:
> "为保研人账号执行热点选题创作，从热点生成到文案输出"

**系统执行**:
1. ✅ 调用 hot-topics-inspiration → 生成10个选题
2. ✅ 展示选题列表，等待用户选择
3. ✅ 调用 xhs-research-copywriting → 创作1500字文案
4. ✅ 保存文案到桌面文件
5. ✅ 输出发布建议（标题、话题标签、配图建议）

**总耗时**: 约3-5分钟（含人工确认环节）

**人工操作**:
1. 查看桌面输出的文案文件
2. 复制纯文本到小红书
3. 根据发布建议配置话题标签
4. 手动点击发布（或后续调用自动发布技能）

3. **数据分析**: 追踪发布后互动数据，优化选题策略
4. **多平台分发**: 扩展至抖音、B站等平台Skill
